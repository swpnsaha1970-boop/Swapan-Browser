# Swapan Browser v4
Chrome-style lightweight Android browser source.

Includes:
- Multi-tab strip (tap to switch, long-press to close)
- Persistent bookmarks and history
- Voice search
- QR scan via standard ZXing intent (no bundled scanner SDK)
- Download manager handoff
- Desktop user-agent mode
- Incognito-style data clearing
- Add shortcut
- Bangla news shortcut
- Third-party cookies blocked
- No analytics/ad SDKs
- Backup disabled
- GitHub Actions debug APK build
